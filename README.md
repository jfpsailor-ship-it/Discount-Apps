# ডিসকাউন্ট স্ক্যানার — নতুন আউটলেটের সেটআপ

## ১. GitHub-এ চালু করা (একবারই)
1. https://github.com এ নিজের অ্যাকাউন্টে লগইন করুন → উপরে **+ → New repository**।
2. নাম দিন (যেমন `Discount-Check-Apps`), **Public** বাছুন → **Create repository**।
3. **uploading an existing file** লিংকে চাপুন। জিপ খুলে ভেতরের **সব ফাইল ও ফোল্ডার** (`index.html`, `sw.js`, `manifest.webmanifest`, `.nojekyll`, `css`, `js`, `libs`, `icons`, `data`) টেনে এনে দিন। (ফোল্ডারের নিজের নাম নয়, ভেতরের জিনিসগুলো।)
4. **Commit changes** চাপুন।
5. **Settings → Pages → Branch: `main`, folder: `/ (root)` → Save**।
6. ১–২ মিনিট পর লিংক পাবেন: `https://ইউজারনেম.github.io/রিপোর-নাম/`

> `.nojekyll` ফাইল না দেখা গেলে আপলোডে বাদ পড়তে পারে। ফাইলটি জিপের ভেতরে আছে, লুকানো ফাইল দেখার অপশন চালু করে নিন।

## ২. নিজের আউটলেটের স্টক ও অফার দেওয়া
1. ফোনে বা কম্পিউটারে লিংকটি খুলুন। প্রথমবার অ্যাপ নিজেই **ডেটা** ট্যাবে যাবে।
2. **১. স্টক ফাইল** → নিজের Stock Report (.xlsx) বাছুন।
3. **২. পুল লিস্ট** → অফিসের Pull Excel বাছুন (থাকলে)।
4. **৪. অফারের নিয়ম** → "বাকি সব পণ্যে ডিসকাউন্ট %" (এখন 26 দেওয়া আছে, বদলানো যায়), বছরের নিয়ম (২০২৪ বা আগে → ৫০%) দেখে নিন।
5. **৫. ভ্যাট** → গার্মেন্টস ১০%, একসেসোরিজ/ফুটওয়্যার ৭.৫%। LABEL গুলো ঠিক আছে কিনা দেখুন (গাঢ় বর্ডার = ৭.৫%)।
6. নিচে **⬇ stock.json** ও **⬇ discounts.json** ডাউনলোড করুন।
7. GitHub রিপো → `data` ফোল্ডার → **Add file → Upload files** → ফাইল দুটি দিন (একই নামে, পুরোনোটি বদলে যাবে) → **Commit changes**।
8. ১–২ মিনিট পর সব স্টাফের ফোনে অ্যাপ খুললেই ডেটা দেখা যাবে।

শুধু নিজের ফোনে দ্রুত দেখতে চাইলে ধাপ ৬–৭ বাদ দিয়ে **এই ফোনে ব্যবহার করুন** চাপুন (অন্য ফোনে যাবে না)।

## ৩. স্টাফদের ফোনে ইনস্টল
- **Android (Chrome):** লিংক খুলে **ডেটা** ট্যাবে "অ্যাপ ইনস্টল করুন", বা ⋮ → Install app।
- **iPhone (Safari):** Share → Add to Home Screen।

## ৪. পরে আপডেট
**ডেটা** ট্যাবে নতুন স্টক/পুল/ডিসকাউন্ট ফাইল দিয়ে ধাপ ২-এর ৬–৮ আবার করুন। নতুন অফার শুরুতে আগে **"নতুন অফার শুরু: সব লিস্ট ও পুল মুছুন"** চাপুন।

## নিয়মের অগ্রাধিকার
পুল লিস্ট → বছর নিয়ম (৫০%) → ডিসকাউন্ট লিস্ট (যেকোনো %) → বাকি সব পণ্যের সাধারণ অফার।
